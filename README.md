## ルール
- キルした数だけマスを進み、止まったマスのブキを使う
- 勝ち試合はキル数そのまま、負け試合はキル数半分（アシスト込み）

## 配信での使い方

- 公開サイト：[Splatoon 3 すごろく](https://hekiruligames.github.io/spla3-sugoroku/)
- ゲーム画面の下に配置する場合は、設定の表示モードで「1行」を選択してください。左から右へ進む横長表示になります。
- Chromeなどのブラウザ画面をキャプチャする方法と、OBSの「ブラウザ」ソースに公開サイトのURLを指定する方法の両方で利用できます。
- OBSブラウザソースでは、幅1440・高さ200を配置の目安にしてください。操作はOBSの「対話（操作）」から行えます。
- 1行表示は「タイトル｜進行操作｜マス数・武器｜盤面」の配置です。OBS表示への切り替えは不要です。
- 設定の「1行サイズ」で画像の大きさを調整できます。1.0〜3.0倍の範囲で、画面の高さに収まるサイズが上限になります。縦の「1列サイズ」とは別々に保存します。
- サイコロ／手入力と表示モードはラジオボタンで選択できます。イカ色も画面内の色見本またはカラーコードで選べるため、外部ポップアップを開く必要はありません。
- 「現在のマス」の種類を表示したい場合は、設定の「開発用情報」をオンにしてください。初期状態では非表示です。
- 表示モードの切り替えでは進行状態を維持しますが、ページの再読み込みではマップと現在位置がリセットされます。ブラウザとOBSブラウザソースのゲーム状態・保存設定は共有されません。
