# spla3-sugoroku
非公式　このプログラムは1人のスプラファンが勝手に作成したものです。

たしさん（Xアカウント：@spl_inkbrush）が企画したスプラすごろくのウェブ版を作成してみました。<br>
たしさんのアイデアをリスペクトしてオマージュいたしました。

## ルール
- キルした数だけマスを進み、止まったマスのブキを使う
- 勝ち試合はキル数そのまま、負け試合はキル数半分（アシスト込み）

## 配信での使い方

- 公開サイト：[Splatoon 3 すごろく](https://hekiruligames.github.io/spla3-sugoroku/)
- ゲーム画面の下に配置する場合は、設定の表示プリセットで「横1行」を選択してください。左から右へ進む横長表示になります。
- Chromeなどのブラウザ画面をキャプチャする方法と、OBSの「ブラウザ」ソースに公開サイトのURLを指定する方法の両方で利用できます。
- OBSブラウザソースでは、幅1440・高さ200を配置の目安にしてください。操作はOBSの「対話（操作）」から行えます。
- 横1行表示は、通常表示と同じ共通操作UIをコンパクトに配置します。OBS専用表示への切り替えは不要です。
- 設定の「マスサイズ」で画像の大きさを0.5〜3.0倍の範囲で調整できます。横1行では描画領域を超えない実効サイズを使い、その他の表示では、はみ出した盤面をスクロールできます。
- サイコロ／手入力は共通操作バーから切り替えます。表示プリセットは「横1行 / 縦1列 / 5列 / 10列」から選択でき、設定ダイアログで即時反映・保存されます。
- カスタム表示では、画面レイアウト、操作パネル位置、進む方向、折り返すマス数・方向を組み合わせられます。マスサイズはプリセットを切り替えても保持されます。
- 盤面上の「見渡す」で15マス折り返しの固定ミニマップを一時表示し、「現在地」で通常のマスサイズと現在位置へ戻れます。
- マスの背面には進行順を示す道が表示されます。未通過部分はグラファイト、通過済み部分とマス外周は選択したイカ色になり、U字カーブと矢印で折り返し方向を確認できます。
- 「現在のマス」の種類を表示したい場合は、設定の「開発用情報」をオンにしてください。初期状態では非表示です。
- 初回だけ、スマートフォン幅・通常画面・高さの低い配信画面の別から表示プリセットの初期値を決めます。以後は選択した表示を保持し、ウィンドウサイズを変えても勝手に設定は切り替わりません。表示変更では進行状態とUndo履歴を維持しますが、ページの再読み込みではマップと現在位置がリセットされます。ブラウザとOBSブラウザソースのゲーム状態・保存設定は共有されません。
